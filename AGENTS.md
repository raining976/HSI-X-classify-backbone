# Project Instructions

## Python Environment

- Use the project environment at `/data2/raining/miniconda3/envs/HSI-X-Classify-Backbone`.
- Run all Python commands, tests, formatters, package checks, and smoke checks with `/data2/raining/miniconda3/envs/HSI-X-Classify-Backbone/bin/python`.
- Do not use bare `python`, `python3`, `pip`, or `pytest` commands.
- Run tests with `/data2/raining/miniconda3/envs/HSI-X-Classify-Backbone/bin/python -m pytest`.
- Install Python development dependencies with `/data2/raining/miniconda3/envs/HSI-X-Classify-Backbone/bin/python -m pip install <package>`.
- Before reporting that a Python dependency is unavailable, check it using the project environment above.
